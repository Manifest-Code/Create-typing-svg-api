# ✨ Typing SVG API

A Flask-based animated typing SVG API.

## Features

- Character-by-character typing animation
- Multiple animated lines
- Custom fonts
- Custom colors
- Custom font size
- Custom typing duration
- Custom pause duration
- Horizontal and vertical centering
- Emoji support

## Example

```text
/typing?font=Quicksand&size=25&duration=3000&pause=1000&color=EAB8E4&center=true&vCenter=true&width=500&lines=Hello+World;Python+Developer;AI+Engineer
